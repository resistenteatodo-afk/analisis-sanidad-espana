# 🏥 Análisis del Sistema Sanitario Español

Este proyecto analiza la relación entre la **inversión por habitante** y la **esperanza de vida** en las diferentes Comunidades Autónomas de España.

## 📊 Visualización Interactiva

Puedes ver la gráfica interactiva funcionando aquí:
👉 [VER PROYECTO ONLINE](https://resistenteatodo-afk.github.io/analisis-sanidad-espana/)

## 🛠️ Tecnologías utilizadas

- **Python 3.x**
- **Pandas**: Para la manipulación y limpieza de datos.
- **Plotly**: Para la creación de visualizaciones interactivas.
- **GitHub Pages**: Para el despliegue del dashboard.

## 🚀 Cómo ejecutarlo localmente

1. Instala las dependencias: `pip install pandas plotly`
2. Ejecuta el script de datos: `python limpieza.py`
3. Genera la visualización: `python grafica.py`
4. Abre `index.html` en tu navegador.
